# Canonical host is the Netlify subdomain

The brand is Ow1.dev, and that name does not resolve. Search engines should treat `https://n1-owl.netlify.app` as the one copy of the site, so name findability can ship on the host that already exists. Buying a domain was the alternative; it stays a later decision, not a blocker for this work.

## Considered options

- Register a domain and make it the canonical host before changing titles or snippets. Rejected because the host that already resolves is enough to be found by name, and the purchase is a separate decision.
